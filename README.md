# Xadrez

Página estática inicial de um projeto de xadrez. No estado atual, a página apresenta um tabuleiro estilizado sobre um fundo escuro; a interação e as regras do jogo ainda não foram implementadas.

## Como executar

Não há dependências ou etapa de compilação. Abra o arquivo `index.html` diretamente no navegador ou sirva a pasta com um servidor local:

```bash
python3 -m http.server 8000
```

Depois, acesse <http://localhost:8000>.

## Estrutura

- `index.html`: página principal e estilos básicos.
- `xadrez.svg`: tabuleiro usado na página.
